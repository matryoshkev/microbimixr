# Developmental cheating by evolved *Myxococcus* bacteria

This data describes the sporulation success of *Myxococcus xanthus*
bacteria in mixed-genotype fruiting bodies. GVB206.3 is an
experimentally evolved genotype. GJV10 is an ancestral genotoype.

## Usage

``` r
data_smith_2010
```

## Format

`data_smith_2010` is a data frame with 28 rows and 5 columns:

- exptl_block:

  Experimental block. Date experiment started (YYYY-MM-DD).

- initial_cells_evolved:

  Initial number of GVB206.3 cells (colony-forming units per plate)

- initial_cells_ancestral:

  Initial number of GJV10 cells (colony-forming units per plate)

- final_spores_evolved:

  Final number of GVB206.3 spores (colony-forming units per plate)

- final_spores_ancestral:

  Final number of GJV10 spores (colony-forming units per plate)
